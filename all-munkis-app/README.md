# All Munkis — app build (Capacitor / Google Play)

This folder is the **Android app** wrap of All Munkis. The live web
version stays at `../all-munkis/` and `madderverse.org/all-munkis/`,
untouched and independently iterable. This copy is what gets bundled
into the AAB uploaded to Google Play.

> **You are reading this because you're about to ship.** The full
> step-by-step (keystore, build, Play Console) is in
> [`CHECKLIST.md`](CHECKLIST.md). This README is the orientation;
> CHECKLIST.md is the runbook.

## What's different from the web copy

`game.js` and `style.css` are byte-identical to `../all-munkis/` —
keep them in sync for gameplay changes. The intentional app-only
differences live entirely in this folder:

| Thing | Web (`../all-munkis/`) | App (here) |
|---|---|---|
| GoatCounter analytics | loaded | **removed** (Play Data Safety = "no data collected") |
| External favicon / site-manifest `<link>`s | absolute madderverse.org URLs | **removed** — runs fully offline |
| Back-to-hub home button + site footer | present | **removed** — no parent site in a standalone app |
| Capacitor native bridge | inert (no `window.Capacitor`) | StatusBar + SplashScreen + Preferences mirror, all feature-detected |
| `<meta>` description / title | SEO copy | app-store copy |

The native bridge in `game.js` is **fully feature-detected**: in a
plain browser `window.Capacitor` is undefined and every native call
is a silent no-op, so this copy still runs as a normal web page for
local testing.

## One-time setup (per machine)

You need **Node 18+** and **Android Studio** (with an Android SDK +
a configured emulator or a real device with USB debugging).

```bash
# from inside all-munkis-app/
npm install
npx cap add android      # generates the android/ project — commit it
npx cap sync             # copies the web build into android/
```

`npx cap add android` only runs once ever (it scaffolds the native
project). After it exists, commit the `android/` folder to the repo.

## Day-to-day

```bash
# after any change to index.html / style.css / game.js / assets:
npx cap sync

# open the native project in Android Studio to build / run / sign:
npx cap open android
```

Local web testing (no Capacitor needed — the bridge is inert):

```bash
npm run serve            # python3 -m http.server 8000
# then open http://localhost:8000/
```

## App icons + splash (raster generation)

The sources in `icons/` and `store-assets/` are **SVG placeholders**
clearly marked `PLACEHOLDER`. Swap them for finished art (spec in
[`store-assets/README.md`](store-assets/README.md)), then rasterize
every density Android needs:

```bash
npm install            # if not already (pulls @capacitor/assets)
npm run assets:generate
```

This reads `icons/icon.svg` + `icons/icon-foreground.svg` +
`icons/splash.svg` and writes the full matrix into
`android/app/src/main/res/mipmap-*/`. Re-run after any icon change.

## Store screenshots

```bash
npm install
npx playwright install chromium
npm run serve                       # terminal 1
npm run screenshots                 # terminal 2
```

Outputs PNGs into `store-assets/screenshots/<profile>/`. Drag-drop
the right folder into the matching Play Console upload slot — the
mapping is in [`STORE_LISTING.md`](STORE_LISTING.md).

## Identifiers (do not change after first publish)

- **Application ID:** `org.madderverse.allmunkis`
  (set in `capacitor.config.json`; mirrored into
  `android/app/build.gradle` `applicationId` by `cap add`)
- **App name:** `All Munkis`
- Once the app is live on Play, the application ID is permanent.
  Changing it = a brand-new app listing.
